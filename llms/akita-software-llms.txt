# Akita Software

> Akita Software was an API observability platform that used passive traffic
> monitoring to automatically discover, map and model APIs without code changes,
> SDKs or proxies. Postman announced its acquisition of Akita on 2023-07-19. The
> technology now ships as Postman Insights, and the agent is open source as the
> Postman Insights Agent.

- [observability-cli](https://github.com/postmanlabs/observability-cli): The original Akita CLI (apidump / apispec / apidiff), formerly akitasoftware/akita-cli. ARCHIVED.
- [observability-shared-libs](https://github.com/postmanlabs/observability-shared-libs): Supporting Go libraries, formerly akitasoftware/akita-libs.
- [Akita Software GitHub organization](https://github.com/akitasoftware): 18 public repositories — Heroku buildpack, NGINX traffic-mirroring module, Docker extension, Kubernetes example, framework integrations for Flask, FastAPI, Django REST Framework and Rails. Most are archived.

## Calling the API

There is NO published OpenAPI, GraphQL schema, AsyncAPI, MCP server or A2A
agent card for Akita or for Postman Insights. The observability API host is
live but publishes no contract.

- Host (US): https://api.observability.postman.com
- Host (EU): https://api.observability.eu.postman.com
- Auth: `x-api-key` header carrying a Postman API key (POSTMAN_API_KEY or
  POSTMAN_INSIGHTS_API_KEY). Legacy Akita keys fall back to HTTP Basic.
- The endpoint surface recorded in this repository is DERIVED from the
  open-source agent's own REST client, not from a provider contract. Do not
  treat it as a callable specification.

## Install the agent

```
bash -c "$(curl -L https://releases.observability.postman.com/scripts/install-postman-insights-agent.sh)"
sudo POSTMAN_API_KEY=<your-api-key> postman-insights-agent ec2 setup --project <projectId> --repro-mode
```
